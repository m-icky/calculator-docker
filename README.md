Calculator App ⚡🧮


A fast and responsive calculator application built using React and Vite, featuring clean UI components, smooth interactions, and efficient state management. The application is fully containerized with Docker for seamless deployment across environments. 🚀

✨ Features

🧮 Modern and responsive calculator UI

⚙️ Efficient state management for real-time calculations

⚡ Built with React + Vite for high performance

🧱 Modular, clean component structure

🐳 Dockerized for consistent deployment everywhere

🛠️ Tech Stack

React

Vite

JavaScript / JSX

Docker

🚀 Getting Started
📌 Prerequisites

Ensure you have:

Node.js (v16+)

Docker (optional for containerized deployment)

📥 Installation
git clone <your-repo-url>
cd calculator-app
npm install
npm run dev
